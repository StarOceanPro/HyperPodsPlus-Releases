# HyperPods+ Downloads

本仓库仅用于发布 HyperPods+ 编译后的 Android 安装包、校验值和测试说明，不包含应用源代码。

## 下载

请前往 **Releases** 页面下载：

- `HyperPodsPlus-1.5.0-release.apk`：普通版，体积更小，日常安装推荐。
- `HyperPodsPlus-1.5.0-debug.apk`：调试版，保留调试信息，体积较大。
- `SHA256SUMS-1.5.0.txt`：安装包完整性校验值。

## 版本

### 1.5.0

- 听音模式液态玻璃胶囊和外部文字布局
- 三段式自定义均衡器
- 二级页面统一滚动、顶部渐进模糊和液态玻璃返回按钮
- 左右耳独立电量岛与充电盒电量切换
- HyperOS 渐变关于页与新版应用图标
